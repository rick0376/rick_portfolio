# Portfólio Rick Pereira

Portfólio profissional de Luis Henrique Pereira, desenvolvido em Next.js.

## Módulo 1 concluído

- Estrutura inicial do projeto
- Página principal responsiva
- Cabeçalho e menu mobile
- Apresentação profissional com foto e marca
- Cards demonstrativos de projetos
- Tecnologias e diferenciais
- Chamada para contato
- Rodapé

## Rodar localmente

```bash
npm install
npm run dev
```

O próximo módulo adicionará o banco PostgreSQL no Neon, Prisma, autenticação administrativa e os cadastros.
